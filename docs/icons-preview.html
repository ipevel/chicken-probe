两块完全一致 —— 因为鸡场 CSS 里 var(--accent) 的引用数是 0（7 处引用全在面板侧： :72 焦点环、:177 兜底 outline、:215 .conn.live、:349 .mid .k b.live、 :386 .spark、:421 .chart .live-dot，以及 :128 的别名）。 而且松绿压在「玻璃叠草地」的合成底 #48603d 上只有 1.11:1 —— 这不是「会不会脏」的审美取舍，是物理上用不了。所以草地 / 天空 / 雾不跟主色走。

计量条三态：空槽 / 点亮 / 越线（.seg 16 格，越线态的既有缺陷）

空槽用的是分隔线 --line（亮 #e5e7ea / 暗 #2a2e35）。 不要把它提到 3:1：一提，「这格亮没亮」的分辨率就从 3.45:1 掉到 1.21–1.86:1，16 格可数性直接失效。 真正该修的是越线态：亮色下 --warn-fill #d98f2b 与空槽只有 2.14:1，涨过 80% 后橙格和空格分不出来。 改法是让 .seg > i.on.warn 用文字档的 --warn（4.19:1），.danger 同理用 --danger（4.79:1）。
